# Adventní kalendář – Oroom

Kopie šablony adventního kalendáře Mobil Maják (bez historie). Princip, mechaniky i služby
(Vite + React + TS, Firebase Auth přes Google, Firestore, Firebase Hosting, GitHub Actions) zůstávají stejné.

**Stav: rozpracováno.** Technické identifikátory jsou přepsané (`oroom-` prefixy, prázdný Firebase config,
ukázkový režim). Značka, obsah, texty a Firebase projekt se doplní podle `docs/NOVY-KLIENT.md`
(hlavně sekce 3, kontrolní seznam). Původní popis fungování je v `docs/README-mobilmajak.md`.
